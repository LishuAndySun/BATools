# 蔚蓝档案行动点工具箱

一个适合局域网使用的轻量 Web 工具。当前版本提供行动点自然恢复计算器和等级目标计算器，后续可以在 `static/` 中按工具拆分页面和模块。

## 技术选择

项目使用 Python 标准库 `http.server` 提供静态文件服务，启动快、依赖少，适合部署在一台电脑上供局域网设备访问。计算逻辑位于独立的浏览器 JavaScript 模块，提醒由实际打开计时器的客户端触发；计时数据只保存在浏览器 `localStorage`，服务器不收集个人数据。

## 安装与启动

需要 Python 3.9 或更高版本。项目没有额外 Python 依赖：

```bash
cd BATools
python3 server.py
```

默认监听 `0.0.0.0:8765`。启动后终端会显示本机访问地址和局域网访问地址。端口可自定义：

```bash
python3 server.py --port 9000
```

正式局域网使用请保留默认的 `0.0.0.0` 绑定。

## 查看本机局域网 IP

启动服务时程序会自动尝试显示局域网 IP。也可以手动查看：

- macOS：终端运行 `ipconfig getifaddr en0`；如果使用其他网络接口，可运行 `ifconfig` 查看对应的 `inet` 地址。
- Windows：命令提示符运行 `ipconfig`，查找当前 Wi-Fi 或以太网适配器的 IPv4 地址。
- Linux：运行 `hostname -I`，或使用 `ip addr` 查看当前网卡的 IPv4 地址。

让手机或另一台电脑连接到同一 Wi-Fi 或局域网，在浏览器打开启动时显示的地址，例如：

```text
http://192.168.1.20:8765
```

无法访问时，检查 Windows 防火墙是否允许 Python 或 TCP `8765` 入站连接；macOS 防火墙是否允许传入连接；Linux 防火墙（如 `ufw`）是否放行 `8765/tcp`。也要确认路由器没有启用客户端隔离。

## 使用行动点计算器

1. 输入当前行动点、行动点上限和记录时间。
2. 点击“现在更新 / 重新记录”。计算器按每 6 分钟恢复 1 点计算。
3. 行动点达到上限后，恢复预测和倒计时会暂停，不会超过上限。
4. 行动点发生变化时重新记录，计时从新的记录时间开始。
5. 页面打开期间每秒刷新显示，恢复到下一点时触发提醒。

点击“启用通知”并允许权限后，恢复时会尝试发送 Web Notification。浏览器通知通常需要 HTTPS 或 `localhost`，且页面或浏览器进程需要保持运行。通过局域网 HTTP 访问时，浏览器可能限制通知权限，这是浏览器安全策略。通知不可用、未授权或被拒绝时，页面仍会显示页内提醒并闪烁页面标题。Windows、macOS 和 Linux 均优先使用浏览器 Web Notifications；项目没有额外原生 Toast 依赖。

## 等级目标计算

“等级目标计算”区域根据当前等级、当前等级已有经验、目标等级、当前行动点、行动点上限和每 AP 获得的玩家经验，计算达到目标等级还需要的经验和行动点。

计算公式为：

```text
当前等级剩余经验 = 当前等级升级所需经验 - 当前等级已有经验
还需要经验 = 当前等级剩余经验 + 中间各等级升级所需经验
还需要行动点 = 向上取整(还需要经验 / 每 AP 获得经验)
还需要等待 AP = max(0, 还需要行动点 - 当前行动点)
等待时间 = 还需要等待 AP × 6 分钟
```

当前版本没有把未经核实的官方等级经验表写进项目。页面中的“经验表配置与数据来源”可以直接编辑 JSON，也可以导入 `.json` 文件。格式是“当前等级到下一级所需经验”，例如：

```json
{
	"1": 100,
	"2": 120,
	"3": 150
}
```

键 `"1"` 的值表示从 1 级升到 2 级需要的经验，不是从 1 级开始的累计经验。计算到目标等级 `N` 时，需要 `N-1` 对应的升级数据；缺少当前等级或中间等级时会停止并显示错误，不会估算。目标等级已经达到时，显示当前等级到下一级还剩多少经验，但不会将其计入目标行动点。

默认规则集中在 [static/game-rules.js](static/game-rules.js)：行动点每 6 分钟恢复 1 点，默认每 1 AP 获得 1 玩家经验。等级经验表默认为空，因为项目没有内置可验证的完整官方数据。用户导入或编辑后的经验表和等级输入保存在当前浏览器的 `localStorage`，不会上传服务器；行动点恢复数据仍使用独立的本地存储键。

如果目标所需行动点超过行动点上限，页面会提示需要分次消耗。等待时间只表示在当前行动点与上限约束下可以自然恢复的部分，不假设一次储存超过上限的行动点。

## 测试

计算核心有独立测试，覆盖恢复边界、上限停止、记录时间边界、等级经验累加、行动点换算、缺失等级数据和无效输入：

```bash
node tests/calculator.test.js
node tests/level-calculator.test.js
```

需要 Node.js 运行测试；生产运行本工具不需要 Node.js。Python 服务可以用以下命令检查语法：

```bash
python3 -m py_compile server.py
```

```text
	├── calculator.test.js    # 行动点恢复测试

```

## 已知限制

- 页面刷新后数据可以从当前浏览器恢复，但不同设备之间不会同步。
- 浏览器关闭或系统休眠期间，客户端提醒无法保证在后台触发；重新打开页面后会根据系统当前时间重新计算。
- 系统时间被手动调整时，计算器会避免显示负数倒计时，并以当前安全时间重新展示结果。
- 当前版本没有账号、权限、云端同步或原生桌面客户端。
